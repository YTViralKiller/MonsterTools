This folder contains a small Phaser 3 demo embedded into index.html.

How it works:
- The game is a simple turn-based combat demo (player vs enemy).
- It uses Phaser 3 via CDN and initializes inside the page's #phaser-root element.
- Controls are provided in the page sidebar: Attack and Heal. Use Exit to close the game section.

To remove:
- Delete the assets/game folder and remove the Game tab and section in index.html.

Notes:
- This is a demo/prototype meant to be extended; it is intentionally minimal to keep the site lightweight.
- Do not copy proprietary assets from other games. Replace placeholder graphics with your own art as needed.
